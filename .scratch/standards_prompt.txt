Review the changes in `.scratch/diff.patch` and `.scratch/commits.txt`.
Standards sources: `PROJECT.md`, `GEMINI.md`, `DESIGN.md`.

Smell baseline:
- Mysterious Name: a function, variable, or type whose name doesn't reveal what it does or holds. -> rename it.
- Duplicated Code: the same logic shape appears in more than one hunk or file in the change. -> extract the shared shape.
- Feature Envy: a method that reaches into another object's data more than its own. -> move the method.
- Data Clumps: the same few fields or params keep travelling together. -> bundle them.
- Primitive Obsession: a primitive or string standing in for a domain concept. -> give it a type.
- Repeated Switches: the same switch/if-cascade recurs. -> replace with polymorphism.
- Shotgun Surgery: one logical change forces scattered edits across many files. -> gather what changes together.
- Divergent Change: one file or module is edited for several unrelated reasons. -> split it.
- Speculative Generality: abstraction, parameters, or hooks added for needs the spec doesn't have. -> delete it.
- Message Chains: long a.b().c().d() navigation. -> hide the walk.
- Middle Man: a class or function that mostly just delegates onward. -> cut it.
- Refused Bequest: a subclass or implementer that ignores or overrides most of what it inherits. -> drop inheritance.

Brief: "Report, per file/hunk where relevant, (a) every place the diff violates a documented standard: cite the standard (file + the rule); and (b) any baseline smell you spot: name it and quote the hunk. Distinguish hard violations from judgement calls: documented-standard breaches can be hard, but baseline smells are always judgement calls, and a documented repo standard overrides the baseline. Skip anything tooling enforces. Under 400 words."
